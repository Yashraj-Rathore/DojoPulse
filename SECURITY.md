# Security policy

DojoPulse is a local research prototype. External service exposure and real provider
activation require the gates in [PRODUCT_PROGRESS.md](PRODUCT_PROGRESS.md).

Report suspected vulnerabilities privately to the repository owner using an existing
trusted contact channel. Do not attach credentials, private footage or player data to
public issues. A dedicated monitored security address/private reporting channel and named
response deputies have not yet been established; this is a release blocker.

The technical maintainer should follow the [incident runbook](docs/operations/security-runbook.md),
record severity and remediation evidence, and obtain independent verification before an
external release. This policy is not a promised response SLA or bug-bounty program.
