# Annotation guide

Watch original-speed context then inspect the exact target window. Record actor independently
of screen side, build evidence, move identity, block, reach/alignment, stance/resources, wall
state, full response window and source timestamps. Mark unknown rather than guess.

Two distinct reviewers independently label eligibility/outcome and confidence. Log actual
seconds. If labels disagree, a third reviewer adjudicates with reason and time; original labels
remain. If both agree, final labels must match. If evidence is unobservable, even an expert
opinion cannot promote it to certain ground truth. A success/failure requires eligibility.

For failed punishment establish that a reviewed response would connect under the observed
conditions and the entire response window contains no qualifying punish. No attack or absent
PUNISH text alone is inadequate. Practice uses the same outcome contract but separate mode.
Include safe, out-of-range, wall, off-axis, wrong-move and incomplete-window negatives.
