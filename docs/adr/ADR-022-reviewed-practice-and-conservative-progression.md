# ADR-022: Reviewed practice and conservative progression

Date: 2026-10-05. Status: accepted for local engineering. Architecture: 2.14.0.

Practice links previously admitted partial/stale captures and used recording start time
as completion. Generic UI setup text also lacked a reviewed version, and self-reported
adherence/progression had no coherent module. Reopen M11.05 and qualify the corrected scope.

Use an optional immutable source-pinned M07 workflow/rules payload, reviewed by both
independent reviewers. Existing drills need a new reviewed version for instructions. Bind
M10-driven assignments to server-recomputed current diagnosis proofs. Freeze the baseline
before linking complete current exact-scope practice; use full source-end chronology and
retain original memberships during reanalysis. Current rights/retention/publication checks
apply to progression and reevaluation under owner/capacity withdrawal locks.

Store append-only adherence reports separately from canonical gameplay/DrillAttempts.
Reports never qualify measured exposure. Owner request UUIDs support safe retries; delete
tombstones prevent resurrection. Account deletion and conservative restore erasure cover
reports and private diagnosis snapshots. Guard migration rollback against lost history.

Next action requires reviewed rules, sufficient compatible evidence and coverage/review
agreement. It can request repetition/review or the declared follow-up, but cannot invent
a harder drill, change a frozen experiment or claim causal benefit. Real G4/expert/player
qualification remains code-gated independently of fixture approvals or trial counts.

See the [practice contract](../architecture/practice-workflow.md) and
[M11 engineering evidence](../experiment-results/m11-practice.md). Native training remains
the comparator and no mod, private provider or live endpoint is introduced.
