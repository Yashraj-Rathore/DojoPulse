# ADR-012 — Practice measurement

Date: 2026-09-18. Status: accepted for local implementation; gameplay release gates remain open.

## Context

Self-report cannot prove execution accuracy.

## Options

Self-report; browser input; recorded game footage; native integration.

## Decision

One recorded native-practice drill with independent human reviews and adjudication.

## Reasoning

Narrowest feasible trustworthy path without a mod.

## Consequences

Drill remains draft until expert review; record disagreement and paid review time.

## Reconsideration trigger

Trusted automated scoring passes G4 or reviewed import adapter reduces cost.
