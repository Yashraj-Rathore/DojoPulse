# ADR-009 — Media retention

Date: 2026-09-18. Status: accepted for local implementation; gameplay release gates remain open.

## Context

Seven days is shorter than the follow-up/audit window.

## Options

Seven-day expiry; indefinite retention; consented study horizon.

## Decision

Study source through 30-day follow-up plus 7-day audit, proposed 60-day maximum.

## Reasoning

Allows correction while bounding privacy/storage.

## Consequences

Explicit consent; deletion overrides study; expired evidence invalidates reruns.

## Reconsideration trigger

Measured needs justify renewed consent or a shorter sufficient horizon.
