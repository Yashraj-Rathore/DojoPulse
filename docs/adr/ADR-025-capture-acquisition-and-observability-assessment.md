# ADR-025: Official-client recordings and non-promoting G1 assessments

Date: 2026-10-05. Status: accepted for local engineering; real acquisition/study approval pending.

The user requested the first real recognition loop and suggested YouTube or direct game
recordings when no private captures/reviewers were supplied. Public discovery did not produce
a qualified exact-build consented dataset. The installed official replay viewer is a candidate
source for player-created recordings, not permission for an undocumented server transport.

Add a reproducible aggregate G1 proposal report over the existing sealed M08 snapshot. Keep
ranked TARGET windows, practice and target-absent controls distinct; preserve unresolved windows,
separate timing completeness from human resolvability, and disclose coverage and external blockers.
The owned API uses existing live privacy/permission checks. Offline reports prove neither current
consent nor source bytes and never approve G1, G2, knowledge, model training or canonical gameplay.
Do not alter the immutable dataset-snapshot/1 QA contract, M09 activation policy or canonical
Match/GameplayEvent/player-model pipeline. Derived reports need no new persistent label store.

Prepare a bounded recording/review procedure and retain dated source findings. No downloader,
scraper, native replay decoder, game automation, private transport or commercial rights grant is
introduced. Actual original footage, exact-build expertise, representative blind labels and
predeclared unseen evaluation remain prerequisites for a real observation detector.
