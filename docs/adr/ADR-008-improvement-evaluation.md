# ADR-008 — Improvement evaluation

Date: 2026-09-18. Status: accepted for local implementation; gameplay release gates remain open.

## Context

The loop's product value depends on credible comparisons.

## Options

Mutable dashboard comparisons; frozen plans/results; causal claim by default.

## Decision

Frozen EvaluationPlan and revisioned ImprovementEvaluation.

## Reasoning

Membership, definitions, chronology and exposure must be reproducible.

## Consequences

Observed change only; compatibility/coverage gates precede statistics.

## Reconsideration trigger

A powered randomized design justifies an additional causal analysis.
