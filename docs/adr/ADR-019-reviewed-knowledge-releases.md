# ADR-019 - Reviewed knowledge releases and patch reanalysis

Date: 2026-10-03. Status: accepted for local synthetic engineering only.
Architecture: 2.11.0. Requirements: M07.02-M07.07, M06.02, M11.01, M12.02,
M14.04-M14.06 and M15.06. Extends ADR-007; does not approve real facts or providers.

Game-build registration, source review, immutable game facts and permission to use
those facts are separate records. An unverified registration never confirms a patch.
Sealed proposals bind exact build/platform, candidate JSON, permitted source reference,
explicit whole-recording sharing, two assigned independent operators, source hashes,
storage generations, metadata, retention deadlines and dependency hashes.

Two independent decisions are required. A reviewer cannot see the other decision until
submitting their own; the author cannot review. Publication creates a new APPROVED
DefinitionVersion, retaining the draft. Immutable status alone does not authorize use:
the release grant and evidence/dependencies must remain available in the correct workspace
and real/synthetic scope. Operator attestations do not prove Tekken expertise. Real
publication is a false code-level gate, and review requires local DEBUG/operator access.
Hosted access and real activation require separate review.

Retirement blocks new use while preserving valid historical measurements. Withdrawal
revokes dependent releases, invalidates conclusions and cancels reanalysis. Source/account
deletion and processing-consent withdrawal erase private candidates, source grants and
notes. Published facts contain no private review provenance and require explicit permission;
immutable permitted facts and nonprivate audit keys remain historical. Restore quarantine
revokes all restored grants before reads, preventing an old backup from reviving withdrawal.
Migration reversal refuses governed history/event pins; empty rollback is rehearsed separately.

Compatibility is an independently reviewed immutable mapping: SAME_MEASUREMENT,
REANALYSIS_REQUIRED or INCOMPATIBLE. It never extends a frozen evaluation's compatible
versions. Bounded canonical reanalysis requires an owned matching capture build/platform and
current source/publication snapshot. Cross-build evidence requires a new baseline. Jobs
use existing admission, budgets, dispatch, isolation and fencing. Media completion still
requires independent annotation import before active gameplay contributions change.

New events pin knowledge to their analysis. Original Match build/initial knowledge stay
unchanged. Older events retain their fallback interpretation; reanalysis cannot rewrite
their hashes or frozen memberships. The annotation validator accepts a governed version
key only for the existing bounded Jin standing block-punish semantics. No expanded detector,
automatic gameplay approval, game scraper, patch safety claim or real-data release is implied.
