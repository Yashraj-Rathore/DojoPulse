# ADR-005 — Overlay versus pure CV

Date: 2026-09-18. Status: accepted for local implementation; gameplay release gates remain open.

## Context

Arbitrary animation recognition is unvalidated.

## Options

Full animation model; overlay extraction; human-only.

## Decision

Overlay/templates first with human adjudication; no automatically released judgment.

## Reasoning

Native indicators constrain positive evidence; absence cannot prove a miss.

## Consequences

Current build/profile and each event class need held-out evaluation.

## Reconsideration trigger

Validated animation model materially improves quality/coverage at acceptable cost.
