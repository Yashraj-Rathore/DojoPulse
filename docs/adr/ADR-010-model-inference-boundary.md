# ADR-010 — Model inference boundary

Date: 2026-09-18. Status: accepted for local implementation; gameplay release gates remain open.

## Context

No training data or evidence that learned models are needed.

## Options

PyTorch now; deterministic templates; hosted model API.

## Decision

No learned inference/LLM now; deterministic report and optional template candidates.

## Reasoning

Accuracy and data collection precede model investment.

## Consequences

SciPy supplies commodity statistical quantiles; not player ML.

## Reconsideration trigger

A held-out classifier gap survives deterministic baselines.
