# ADR-023: Prospective collection, exact provenance and phased longitudinal reports

Date: 2026-10-05. Status: accepted for local engineering; real study/release gated.

The existing frozen statistical comparison lacks explicit later retention, missing-session
accounting and decoder provenance. Favorable selected captures and stale evidence could
otherwise make historical software results appear current.

Extend immutable plans with optional scheduled protocols while preserving legacy hashes.
Require real plans to predeclare collection and pin exact source/measurement/decoder scope.
Evaluate all recorded target evidence, treat absent publication as a gap and keep append-only
owned session receipts separate from verified exposure. Follow-up/retention use the same
baseline and original practice window; retention references a current initial result.
Use owner/capacity/plan locks, immutable revisions and revocable private report projections.
Export reproducible safe reports and erase receipts/invalidate results during account
deletion and quarantine restore. Guard populated migration rollback.

Provide baseline-only session variance/planning diagnostics without post-hoc power or any
real efficacy assertion. Keep all six outcomes and existing uncertainty method. Exact-source
abstention can require a new baseline even where sources might be equivalent; explicit real
bias validation is needed before relaxing that policy. User reports cannot reveal every
unsubmitted match or prove real session independence. M12.08 qualifies software only;
M12.05–M12.07/G5/G6 need actual consented cohorts, approved measurement/drill and study review.

See [contract](../architecture/longitudinal-evaluation.md) and
[qualification](../experiment-results/m12-comparisons.md). No provider activation,
undocumented transport, recognizer release, cloud provisioning or causal claim is authorized.
