# First-situation selection — provisional experiment, not release approval

Score = importance x observability x natural frequency x trainability x measurement reliability.
Each factor is 1-5. The following are engineering priors, NOT measured scores. Frequency is
unmeasured in our cohort; report it as such. A low factor is not compensated away in release gates.

Jin/Jin is a controlled pilot cohort choice: one vocabulary, mirrored visuals stress stable
participant identity. It is not assumed representative of the whole player base. Switching to
a better-observed matchup is an ADR revision, not expansion of simultaneous supported scope.

| Candidate | Observability/indicators | Knowledge/CV risk | Practice/transfer/sample need |
|---|---|---|---|
| Simple block punish | command history plus block/contact; PUNISH for positives only | uf+4 identity, range and response require current-build expert verification; no native missed indicator assumed | simple recording slots; matched failures need full-window review; >=40 outcomes/period exploratory, >=5 sessions |
| Rage Art | conspicuous animation; positive PUNISH cue | long effects/timing; old frame values cannot be reused blindly | easy scripted practice, possibly rare natural exposure; same minimum counts may take longer |
| Throw break | throw/break animation and input | type, breakability, counter state and timing ambiguity | randomized throws possible; type-stratified outcomes increase sample demand |
| Duckable string | sequence input and hit-level evidence | continuation, delay and intentional interruptions | straightforward slots, but natural completed strings may be sparse |
| Negative challenge | input/recovery alignment | descriptive attack is observable only sometimes; normative bad choice especially unreliable | poor universal success predicate; reject for first experiment |
