# Improvement loop

Play -> confirm target opportunities -> freeze baseline -> choose one weakness -> assign
one draft/approved drill -> measure real practice -> collect later matches -> freeze follow-up
membership -> check compatibility -> evaluate observed change -> choose next action.

Verified human-reviewed practice is allowed; self-report is adherence only. Assignment time
does not establish exposure. Follow-up must start after the recorded practice exposure cutoff,
using played-at with known timezone/certainty, not upload time.

| Result | Next action |
|---|---|
| OBSERVED_IMPROVEMENT | Maintain and check retention; no causal claim |
| OBSERVED_DETERIORATION | Review evidence, context and intervention |
| NO_MEANINGFUL_CHANGE | Revise drill after checking adherence and precision |
| INSUFFICIENT_EXPOSURE | Gather opportunities; reconsider target frequency |
| NOT_COMPARABLE | Repair versions/context/chronology or establish a new baseline |
| INCONCLUSIVE | Gather independent sessions; do not force an answer |

Weakness ranking considers frequency, lost value, confidence and trainability. No normative
label follows merely from a high P(action|situation). Native replay/training is the comparator.
